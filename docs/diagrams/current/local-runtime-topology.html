Ejecución local de SGI-Curime

Procesos del host, contenedor de datos y configuración necesaria al 13 de agosto de 2026.

Cómo arrancan

Las dos aplicaciones conservan instalaciones npm independientes. El backend carga backend/.env, requiere DATABASE_URL durante la construcción de PrismaService y escucha en PORT o 3000. Compose publica PostgreSQL en localhost:5432; no inicia frontend ni backend.

Límites actuales

  • Vite no define proxy ni puerto explícito.
  • Nest no habilita CORS.
  • No existen Dockerfiles para las aplicaciones.
  • El seed exige DATABASE_URL y cuatro variables ADMIN_*.
