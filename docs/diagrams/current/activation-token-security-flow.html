Ciclo de vida del token de activación

Separación entre secreto en claro, hash persistido y consumo atómico al 13 de agosto de 2026.

Controles verificados

El token usa 32 bytes aleatorios codificados en base64url. Solo se persiste SHA-256(token); la entrada recibida se transforma con el mismo hash para buscar el registro. El consumo y la activación ocurren en una transacción, con filtros repetidos de usedAt, expiración y estado para resistir intentos concurrentes.

Brecha operativa

  • deliver() no tiene proveedor implementado.
  • La aprobación no devuelve el token en la respuesta.
  • No hay reemisión ni revocación explícita de tokens.
  • Eliminar al usuario elimina sus tokens en cascada.
